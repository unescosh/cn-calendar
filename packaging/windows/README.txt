中国日历 · Windows 10 免安装版
================================

1. 双击 cn_calendar.exe 打开日历。
   请把整个文件夹一起保留，不要只把 exe 单独拖到桌面：
   它旁边必须有 data 文件夹、cn_cal_cli.exe 和几个 dll。

2. 开机自启（可选）：双击 enable-autostart.bat
   看到 Done 就表示已开启，下次登录 Windows 会自动启动。
   只写当前用户的注册表 Run 项，不需要管理员权限，
   不影响其他账户，也不改系统自带组件。

3. 取消自启：双击 disable-autostart.bat

4. 数据说明：日历数据全部内置，断网也能用。
   联网只用于核对日期/星期、同步国务院年度放假调休安排；
   固定纪念日、农历、节气不会被联网数据改写。
   无账号、无会员、无广告、无备忘录、无遥测。

5. 出问题时：把界面上那行报错原文发回即可，
   不要单独移动或删除本文件夹里的任何文件。

6. 若界面显示「无法读取日历核心」：
   先确认 cn_cal_cli.exe 和 cn_calendar.exe 在**同一个文件夹**。
   不在 → 多半下载成了 cn-calendar-windows-x64（开发用原始目录），
   请重新下载 cn-calendar-windows-portable 并完整解压。
   在但仍报错 → 可能被安全软件隔离，恢复该文件并加入信任即可。
   报错文字里会直接给出程序实际去找的完整路径。

7. 两个 exe 明明在同一个文件夹，却报 FormatException 或满屏乱码：
   这是旧版绿色包在中文 Windows 上的编码问题（计算核心输出 UTF-8，
   界面却按 GBK 去读）。本版已经修好，请重新下载最新版
   cn-calendar-windows-portable 并完整覆盖解压。
   旧包必现，不用改系统区域设置、不用装字体、不需要管理员权限，
   也跟杀毒软件无关。若新版仍报错，把界面上那行报错原文截图发回即可。
