## 五、Win10 正式安装与自启落地（2026-11-10 16:17 本机执行）

此前程序只在 `Downloads` 下试跑，注册表与启动文件夹都没有自启项。本轮补齐：

| 项 | 值 |
|---|---|
| 安装目录 | `%LOCALAPPDATA%\CNCalendar\`（用户级，无需管理员；原 Downloads 试跑包保留未删） |
| 两个 exe | 同目录：`cn_calendar.exe` 89,600 字节 + `cn_cal_cli.exe` 445,440 字节 |
| 目录内容 | 6 个文件 + `data\`：主程序、CLI、`flutter_windows.dll`、两个自启开关 bat、`README.txt` |
| 自启项 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `CnCalendar` = `"C:\Users\unesc\AppData\Local\CNCalendar\cn_calendar.exe"` |
| 关闭方式 | 双击安装目录里的 `disable-autostart.bat`；不改系统组件、不动其他账户 |
| 验证 | 注册表值读回正确、目标 exe 存在；从新目录跑 CLI，中文 / 数据 / 星期核对全部通过 |

UOS 侧由 deb 自带 `/etc/xdg/autostart/cn-calendar.desktop`；免 sudo 时走 `install-user.sh` → `~/.config/autostart/`。
两端自启都**不重启、不注销**验证过「自启项落地 + 能弹窗」，真正开机自启留到下次自然开机观察。
