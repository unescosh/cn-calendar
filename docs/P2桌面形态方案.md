## 二、需求 1：点任务栏时间弹出本软件界面

### 原则

用户明确「是否真正替换系统自带日历并非必须，只要效果满足即可」。
因此**不修改、不禁用、不注入系统组件**，只让本软件接管「用户点时间」这个动作，
弹出的是**现有 Flutter 月历窗口本身**——不另写一套界面，数据链路与 JSON 契约不变。

### Windows 10

- 微软没有公开接口允许第三方替换任务栏时钟弹出的日历面板。
- 可行路径（业界同类做法）：托盘常驻 + 低级鼠标钩子识别时钟区域
  （Win10 `TrayClockWClass`）点击 → 显示本软件窗口；自绘时钟覆盖为可选项。
  同类开源实现：UpCalendar、CornerCalendar；GitHub `renber/TaskbarExtensions`
  自己声明「使用微软未公开支持的方法、依赖任务栏实现细节，系统更新后可能失效」。
- **兜底**：钩子失效时托盘图标仍可一键打开，不会出现「点时间没反应又没有替代入口」。
- 风险登记：Win10 更新或任务栏实现变化后需回归验证；不做驱动、不做进程注入、不写系统目录。

### 统信 UOS 20 / DDE

- DDE 有官方 Dock 插件接口（wiki.deepin.org「Dock插件开发」、`dde-dock-dev`；
  `PluginItemInterface` 的 `itemWidget` / `itemPopupApplet`，新版为
  dde-shell / dde-tray-loader + QML），比 Windows 侧规范。
- 首选：做一个 Dock 插件，点击后通过 D-Bus / 进程间消息唤起本软件月历窗口。
  次选：仅托盘图标 + 点击弹出，不依赖插件 ABI。
- 插件要用 Qt/C++ 或 QML 写，与 Flutter 界面不是同一套代码，但**只做入口，不渲染日历**。
- 版本风险：UOS 20 实机 DDE 2026.1076.1，实现前须确认是老 `dde-dock`
  还是新 `dde-shell`，插件 ABI 与版本强绑定，不能靠推测。
- **不禁用系统自带时间插件**：并列放置，避免动系统配置、避免影响办公环境里其他软件。

## 三、需求 3：开机自启

| 平台 | 机制 | 权限 | 关闭方式 |
|---|---|---|---|
| Win10 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入本程序路径 | 无需管理员 | 软件内开关 / 删除该键值 |
| UOS 20 | `~/.config/autostart/cn-calendar.desktop`（XDG Autostart 规范） | 仅当前用户 | 软件内开关 / 删除该文件 |

- 桌面挂件与主窗口由**同一个进程**承载，开机自启只拉起一个进程，
  不额外常驻子进程（P3 的 FFI 替换 CLI 桥接也是为此）。
- 默认开启，但设置里必须有显式开关；安装/卸载脚本要能干净地添加与删除。
- 开机自启后首次启动仍走完整首次校准（无报告缓存时），之后按定期校准节流。

## 四、与低资源约束的关系（需求 2）

挂件是长期常驻形态，比一次性窗口更容易累积占用，必须遵守
`docs/资源占用规范.md` 的 P2 硬约束：

- 窗口隐藏 / 最小化时暂停渲染与刷新，不保持 vsync 回调；
- 只在「日期跨天」「用户主动翻开月历」「L4 数据更新」三种情况重绘；
- 不做无限循环动画、不做周期轮询、不做后台定时器、不上报遥测；
- 上线前两台目标机各连续运行 24 小时，记录空闲内存 / CPU 曲线，确认无内存漂移。

定期校准口径（本轮已落地，详见 `docs/数据核对规范.md` 第六节）：

- 本地计算每次启动照常执行，零网络、零额外进程；
- 联网权威日期核对 + 11323 天星期连续性 + L4 差异报告：默认每 **7 天**一轮；
- L4 年度调休同步：**11～1 月每天**查公告，其余月份 **30 天**查一次；
- 上次离线：**6 小时**后重试；跨年或系统时钟回拨：强制重跑；
- 用户随时可点核对图标 →「立即校准」，跳过节流走完整核对。

精确性不降：L1/L2/L3 不被联网改写，差异一律出报告，
L4 更新立即清空月份缓存并重取当月，不会显示过期的放假/补班。

第 3 步按用户「开始做P2」启动，**只做 Win10**：Win10 时钟区是
`TrayClockWClass`，可用只读低级鼠标钩子接管；UOS 侧 DDE Dock 插件的 ABI
与 `dde-dock` / `dde-shell` 代际强绑定，目标机 DDE 2026.1076.1 属于哪一代
尚未实机确认、且机上无 Qt 工具链，**不臆测 ABI 就写代码**。
这一步 Linux runner / Dart 数据链路零改动，UOS 正式包产物不变、无需重装。

实现与验收细节见 `docs/P2第一步_Win10托盘与时间接管.md`。

第 4 步按用户「先做WIN10桌面挂件」启动，同样**只做 Win10**：Dart 用
`ui.PictureRecorder` 离屏把整月画成一张 32bpp 位图，原生层只做 `BitBlt`，
不碰 Flutter embedder C++ API；挂件窗口复用主线程消息循环，不新增进程 /
线程 / 定时器。跨天精准靠一个每 30 分钟只比一次日期字符串的哨兵，
日期变化才重绘一次。刻意不改 `main.yml` 与补丁脚本，避免隐藏 `.github`
漏替换重演。设计与契约见 `docs/P2第二步_Win10桌面挂件.md`。
